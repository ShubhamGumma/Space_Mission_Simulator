# Space Mission Simulator

A browser-based spacecraft docking simulator built with p5.js and p5.play.

## Overview
Pilot a spacecraft using the arrow keys and attempt to dock with the ISS. The sprite swaps direction images as you steer left/right, and includes a subtle drift so the ship doesn't hold perfectly still — you have to actively correct your approach.

## Controls
- **Left/Right arrow keys** — steer the spacecraft toward the station

## Tech
- **Library:** [p5.js](https://p5js.org/) + p5.play (sprite handling) + Matter.js (physics)
- **Language:** JavaScript

## Run it
Open `index.html` in a browser — no build step required.
